# 单词花园 · Word Garden

《植物大战僵尸》风格的英语单词拼写游戏。拼对单词获得阳光和魔法弹，种植物、守草坪。

![原创矢量素材 · 无外部素材依赖](https://img.shields.io/badge/assets-original%20SVG-63b32e)

## 运行

需要 Node.js（仅用于启动静态服务器，无第三方依赖）：

```bash
npm run dev
# 或
node server.mjs
```

然后打开 <http://localhost:5173>。

也可以直接双击 `index.html` 打开，但浏览器对 `file://` 下的 ES Module 有限制，推荐用上面的方式。

## 玩法

- **拼写 → 资源**：答对一个单词获得 `+10` 阳光，连击 ≥3 时额外 `+5`，并积攒 25 点单词能量。
- **魔法弹**：每次答对会向场上最靠前的僵尸发射一发魔法弹（45 伤害）。
- **单词风暴**：能量满 100 后点击按钮，全屏僵尸受到 260 伤害并被减速。
- **答错**：连击清零，锁定 1.4 秒；同一单词错 2 次会自动提示首字母。
- **种植**：点击顶部卡片（或按数字键 1–5），再点草坪格子。5 种植物：向日葵、豌豆射手、坚果墙、寒冰射手、樱桃炸弹。
- **失败条件**：僵尸走到房子且该行小推车已用掉。

## 两种拼写模式

- ⌨️ 键盘拼写：直接敲键盘，拼满自动判定。
- 🔤 点选字母：从打乱的字母块（含 2 个干扰字母）里点选，支持删除。

菜单和游戏内右上角都可以切换。

## 导入自己的词表（CSV / 教材单元）

菜单右上角「📥 导入词表」：一个文件 = 一个单元，导入后立刻出现在关卡列表中，可删除。

最简格式（每行一个单词，英文 + 中文即可）：

```csv
apple,苹果
rainbow,彩虹
library,图书馆
```

完整格式（表头可选，emoji / 音标 / 例句可留空）：

```csv
en,zh,emoji,ipa,example
apple,苹果,🍎,/ˈæpl/,I eat an apple every day.
rainbow,彩虹,🌈,/ˈreɪnbəʊ/,A rainbow is in the sky.
library,图书馆,📚,/ˈlaɪbrəri/,We read books in the library.
```

- 分隔符支持逗号、制表符、中文逗号、分号或空格（`apple 苹果` 也可以）。
- 英文限 2–20 个字母；中文释义必填；重复单词自动去重。
- 单个词表最多 300 词，自定义词表总量最多 3000 词。
- 词表保存在浏览器 `localStorage`（`word-garden-custom-units-v1`），不会上传到服务器。
- 导入弹窗内可「载入示例」或「下载 CSV 模板」。

## 错词复习（遗忘曲线）

- 答错或跳过的单词会进入记忆库，按英文单词全局记录（跨关卡、跨词表复用）。
- 关卡结算时，主按钮会变成「📚 复习错词」，并在 6 秒后自动开始本关错词复习（可点「暂不复习」取消）。
- 菜单「🔁 复习错词」显示当前到期数量；答对后按间隔重复安排下一次：1 天 → 约 2 天 → 约 5 天……最长 60 天。
- 复习中拼错或跳过，10 分钟后再次到期；记忆库保存在 `word-garden-srs-v1`。
- 复习界面同样支持键盘输入和点选字母。

## 词库与关卡

- 5 个主题单元（动物 / 食物 / 校园 / 自然 / 动作），每个 12 词，共 60 词，另可导入自定义词表。
- 每个单元 3 个难度，难度决定僵尸波次、数量和血量，不影响词库。
- 进度、星级、拼写模式保存在 `localStorage`：`word-garden-progress-v1`。
- 内置词库在 `src/words.js`，按 `{ en, zh, emoji, ipa, example }` 结构扩展即可。
- 数值、波次、关卡节奏在 `src/config.js`。

## 项目结构

```
index.html          页面骨架（菜单 / 游戏 / 弹层）
styles.css          全部样式（舞台 1760×760，按窗口等比缩放）
server.mjs          零依赖静态服务器
src/
  main.js           菜单、导入词表、进度、复习入口、结算
  game.js           游戏主循环：僵尸/植物/子弹/阳光/小推车
  spelling.js       拼写面板：出题、判定、两种输入模式、错词本
  wordstore.js      自定义词表：CSV 解析、导入、删除
  srs.js            遗忘曲线：错词调度与到期查询
  review.js         弹窗式错词复习（键盘 + 点选字母）
  words.js          内置词库
  config.js         数值与波次
  audio.js          Web Audio 实时合成音效（无音频文件）
  speech.js         浏览器语音合成（朗读单词）
  ui.js             弹窗、飘字、星级
assets/original/    原创 SVG 美术：草坪、植物、僵尸、阳光、小推车
```

## 素材与版权

- 美术全部为本项目手写的原创 SVG（`assets/original/`），音效由 Web Audio 实时合成，**不包含任何《植物大战僵尸》原版素材**，可自由部署、分发与商用。
