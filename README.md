# 单词花园 · Word Garden

《植物大战僵尸》风格的英语单词拼写游戏。拼对单词获得阳光和魔法弹，种植物、守草坪。内置鲁教版五四制初中英语 48 个教材单元。

![素材](https://img.shields.io/badge/assets-PvZ%20classic%20%2B%20original%20SVG-63b32e)

## 运行

需要 Node.js（仅用于启动静态服务器，无第三方依赖）：

```bash
npm run dev
# 或
node server.mjs
```

然后打开 <http://localhost:5173>。

也可以直接双击 `index.html` 打开，但浏览器对 `file://` 下的 ES Module 有限制，推荐用上面的方式。

## 玩法

- **拼写 → 资源**：答对一个单词获得 `+10` 阳光，连击 ≥3 时额外 `+5`，并积攒 25 点单词能量。
- **魔法弹**：每次答对会向场上最靠前的僵尸发射一发魔法弹（45 伤害）。
- **单词风暴**：能量满 100 后点击按钮，全屏僵尸受到 260 伤害并被减速。
- **答错**：连击清零，锁定 1.4 秒；同一单词错 2 次会自动提示首字母。
- **种植**：点击顶部卡片（或按数字键 1–5），再点草坪格子。5 种植物：向日葵、豌豆射手、坚果墙、寒冰射手、樱桃炸弹。
- **自动种植**：顶栏 🤖 按钮控制，默认开启；自动收阳光、种向日葵，并按僵尸所在行补种豌豆/寒冰。
- **失败条件**：僵尸走到房子且该行小推车已用掉。

## 两种拼写模式

- ⌨️ 键盘拼写：直接敲键盘，拼满自动判定。
- 🔤 点选字母：从打乱的字母块（含 2 个干扰字母）里点选，支持删除。

菜单和游戏内右上角都可以切换。

## 手机 / 平板

- 触屏设备自动启用游戏内屏幕键盘，不再弹出系统键盘遮挡画面。
- 键盘上方始终能看到单词卡、拼写格和输入框；键盘栏可点「提示 / 跳过 / 收起」。
- 键盘包含字母、数字和删除键；切换点选字母模式时自动隐藏。
- 右侧拼写面板在触屏下会自动加宽，字体、字母格和按键同步放大。
- 横屏显示更完整；竖屏顶部会提示「横屏游玩更清楚」。

## 教材关卡（鲁教版五四制）

内置鲁教版五四制初中英语六册教材词表：**48 个单元、2161 个词条**（六上 / 六下 / 七上 / 七下 / 八上 / 九全）。

- 菜单顶部的分册标签切换教材：`主题 / 六上 / 六下 / 七上 / 七下 / 八上 / 九全 / 自定义`。
- 每个教材单元就是一个关卡，和主题单元一样有 3 个难度、星级与解锁。
- 一局会从该单元词表中循环出题，重玩会覆盖更多单词。
- 短语也能拼：空格、撇号、连字符、句点会自动补全，只需要输入字母和数字。例如 `You're welcome` 输入 `yourewelcome` 即可，`3D` 输入 `3d`。

## 导入自己的词表（CSV / 教材单元）

菜单右上角「📥 导入词表」：一个文件 = 一个单元，导入后立刻出现在关卡列表中，可删除。

最简格式（每行一个单词，英文 + 中文即可）：

```csv
apple,苹果
rainbow,彩虹
library,图书馆
```

完整格式（表头可选，emoji / 音标 / 例句可留空）：

```csv
en,zh,emoji,ipa,example
apple,苹果,🍎,/ˈæpl/,I eat an apple every day.
rainbow,彩虹,🌈,/ˈreɪnbəʊ/,A rainbow is in the sky.
library,图书馆,📚,/ˈlaɪbrəri/,We read books in the library.
```

- 分隔符支持逗号、制表符、中文逗号、分号或空格（`apple 苹果` 也可以）。
- 英文 2–30 个字符，可包含空格、撇号、连字符、句点，支持 `You're welcome`、`ice cream` 这类短语；中文释义必填；重复单词自动去重。
- 单个词表最多 300 词，自定义词表总量最多 3000 词。
- 词表保存在浏览器 `localStorage`（`word-garden-custom-units-v1`），不会上传到服务器。
- 导入弹窗内可「载入示例」或「下载 CSV 模板」。

## 错词复习（遗忘曲线）

- 答错或跳过的单词会进入记忆库，按英文单词全局记录（跨关卡、跨词表复用）。
- 关卡结算时，主按钮会变成「📚 复习错词」，并在 6 秒后自动开始本关错词复习（可点「暂不复习」取消）。
- 菜单「🔁 复习错词」显示当前到期数量；答对后按间隔重复安排下一次：1 天 → 约 2 天 → 约 5 天……最长 60 天。
- 复习中拼错或跳过，10 分钟后再次到期；记忆库保存在 `word-garden-srs-v1`。
- 复习界面同样支持键盘输入和点选字母。
- 手机/平板复习时使用底部屏幕键盘，右上角 ✕ 可随时关闭复习。

## 经典皮肤与素材切换

- 默认使用 `assets/pvz/` 里的经典 PvZ 美术、GIF 动画和 MP3 音效，本地和线上一致。
- 切回原创 SVG + Web Audio 合成音效：在网址后加 `?skin=original`；切回经典：`?skin=classic`。选择会记在 `localStorage`。
- `assets/pvz/` 现在会随项目提交和部署；公开站点因此包含《植物大战僵尸》原版提取素材，仅供个人学习体验，存在版权与下架风险。正式分发或商用请改用 `?skin=original` 的原创素材，或删除 `assets/pvz/`。

## 词库与关卡

- 5 个主题单元（动物 / 食物 / 校园 / 自然 / 动作），每个 12 词，共 60 词。
- 鲁教版六册 48 个教材单元，共 2161 个词条；另可导入自定义词表。
- 每个单元 3 个难度，难度决定僵尸波次、数量和血量，不影响词库。
- 进度、星级、拼写模式保存在 `localStorage`：`word-garden-progress-v1`。
- 内置词库在 `src/words.js`，按 `{ en, zh, emoji, ipa, example }` 结构扩展即可。
- 数值、波次、关卡节奏在 `src/config.js`。

## 项目结构

```
index.html          页面骨架（菜单 / 游戏 / 弹层）
styles.css          全部样式（舞台 1760×760，按窗口等比缩放）
server.mjs          零依赖静态服务器
src/
  main.js           菜单、分册标签、导入词表、进度、复习入口、结算
  game.js           游戏主循环：僵尸/植物/子弹/阳光/小推车
  spelling.js       拼写面板：出题、判定、两种输入模式、错词本
  textbook.js       鲁教版六册 48 单元 / 2161 词条
  wordstore.js      自定义词表：CSV 解析、导入、删除
  srs.js            遗忘曲线：错词调度与到期查询
  review.js         弹窗式错词复习（键盘 + 点选字母）
  words.js          内置主题词库
  skin.js           皮肤选择：默认经典，可切原创
  config.js         数值、波次、双皮肤素材路径
  audio.js          经典 MP3 池 + Web Audio 合成音效
  speech.js         浏览器语音合成（朗读单词）
  ui.js             弹窗、飘字、星级
assets/original/    原创 SVG 美术：草坪、植物、僵尸、阳光、小推车
assets/pvz/         经典 PvZ 素材：图片、GIF 动画、MP3 音效
```
